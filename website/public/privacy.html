Privacy Policy

Effective October 16, 2026

Scope and operator

This notice describes the AfricAndroid public website and release API operated by Olamide Olatayo Bello. Installed applications, SIP services and external websites may process different information; review their disclosures and permissions separately.

Information processed

Your browser requests pages, images, release metadata and APK files. Hosting access and error logs may record your IP address, request path and query string, timestamps, response status, browser information and referring page. The release API also writes operational request logs to the service journal. The release database stores published application metadata, rather than visitor accounts or download profiles.

Search, cookies and clipboard

The current website filters downloaded release metadata in your browser. Direct requests to the API using search parameters send those parameters to the server and may appear in logs. The website does not set application cookies or include advertising or analytics scripts. Selecting “Copy file checksum” writes the displayed checksum to your clipboard; it does not read your clipboard.

Purpose, access and retention

Operational information supports delivery of downloads, security, troubleshooting and service reliability. Authorized operators and hosting providers may access server records for these purposes. Information may also be disclosed when required by applicable law. Log retention follows server and hosting configurations; this notice does not promise a fixed deletion period. The release database is retained to operate the download catalog.

External links and application permissions

GitHub and other external destinations apply their own privacy practices. The website does not request your contacts, microphone, messages or location. Permissions requested by an installed APK are separate from website use.

Requests and updates

For privacy questions or to request a private contact channel, use the project issue tracker. Issues are public: do not post identity documents, passwords, IP logs or other sensitive information. Requests concerning access, correction or deletion will be considered as applicable, subject to identity verification and operational or legal requirements. Updated practices will be reflected on this page with a revised effective date.
