Website privacy

This public website serves project information and APK downloads. It does not request accounts, collect payment details, use analytics scripts or set application cookies.

The hosting server may record IP addresses, request paths, timestamps and browser information in standard access and error logs for operation and troubleshooting. Server operators control log access and retention.

GitHub links take you to an external service with its own privacy practices. Installed APKs have their own permissions and behavior; this notice covers the website only. Review the source and release notes before installing.

Project contact: GitHub project issues. Do not post passwords or private information.
