About the operating system

An APK installs an app; it does not replace your phone’s operating system. A complete AfricAndroid OS image has not been compiled or boot-validated. The current source targets an x86_64 Cuttlefish virtual phone, not arbitrary consumer phones.

BEFORE YOU TAP INSTALL

A few simple checks.
A better first start.

Install only a build you trust. Development APKs are for evaluation and may have incomplete features.

Read the capability report ↗
  1. 1

    Match your Android device

    Check minimum Android API level, supported CPU architecture and release notes on the download card.

  2. 2

    Verify the download

    Compare the file’s SHA-256 with the published value. Check the signing fingerprint before trusting a new release.

  3. 3

    Install with care

    Open the APK and, if prompted, allow installation from that browser temporarily. Restore the restriction afterward. A different signing key may block an update.

  4. 4

    Choose your permissions

    Grant only permissions needed for the features you use. APK downloads do not include configured SIP service or Google Play licensing.
